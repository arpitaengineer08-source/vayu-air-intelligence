# Contributing

Thanks for your interest in contributing to VAYU.

## Getting started
1. Fork and clone the repository.
2. Create a Python virtual environment.
3. Install dependencies with `pip install -r requirements.txt`.
4. Follow the README to run the pipeline and launch the Streamlit app.

## Contribution guidelines
- Preserve the distinction between synthetic demo data and live/model-based data.
- Do not present the Pollution Disruption Index as an official regulatory index.
- Treat observed relationships as associations, not proof of causation.
- Add or update tests for pipeline, validation, forecasting or index changes.
- Run `pytest` before submitting a pull request.
- Do not commit API keys, credentials, virtual environments or generated local databases.

## Pull requests
Describe the change, its rationale, validation performed and any impact on outputs. Include screenshots for UI changes when relevant. Open an issue first for larger feature proposals.
